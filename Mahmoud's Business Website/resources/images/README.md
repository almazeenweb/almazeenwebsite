# Image placeholders

Files still marked as placeholders below are lightweight SVGs standing in for real photos.
Replace them with real images using the **same filename** (or update the `src`/`href` in
`index.html` if you rename them) and the site will pick them up automatically.

| File | Used for | Recommended size |
|---|---|---|
| `hero.webp` | Hero banner background on the homepage | ~1600 x 900px, landscape job-site or roofline photo |
| `about.webp` | Photo next to the "Homeowners" section | ~1000 x 800px, team or job-site photo |
| `og-image.jpg` *(not yet created)* | Social share preview (Facebook/LinkedIn/Twitter) | 1200 x 630px, JPG or PNG — SVG/WebP are not reliably supported by all social crawlers |

Other brand assets live in `resources/` directly (not in this folder):

- `resources/logo.svg` — icon mark used in the site header/footer: a roofline feeding into a gutter trough, downspout, and water drop. Finished, not a placeholder.
- `resources/favicon.svg` — browser tab icon, a bolder/simplified two-line version of the mark for legibility at small sizes.
- `resources/logo-horizontal.svg` — icon + "Al Mazeen Gutter LTD" wordmark lockup, not currently used on the site itself, but handy for things like business cards, letterhead, invoices, or truck signage.
